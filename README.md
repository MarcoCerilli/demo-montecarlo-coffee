# Montecarlo Specialty Coffee | Torrefazione Artigianale D2C

Mini e-commerce D2C veloce con carrello slide-over interattivo, barra progresso spedizione gratuita, selezione macinatura e codici sconto.

## 🚀 Guida Rapida Deploy su Vercel

Questo progetto è un'applicazione React + Vite + Tailwind CSS autonoma e indipendente al 100%, pronta per essere caricata su una repository GitHub dedicata e pubblicata su Vercel.

### 1. Esegui in Locale
```bash
npm install
npm run dev
```

### 2. Build di Produzione
```bash
npm run build
```

### 3. Pubblicazione su GitHub & Vercel
1. Crea una nuova repository su GitHub: `https://github.com/new` (es. `montecarlo-coffee-ecommerce-demo`).
2. Inizializza Git e carica il codice:
```bash
git init
git add .
git commit -m "feat: initial commit for Montecarlo Specialty Coffee | Torrefazione Artigianale D2C"
git branch -M main
git remote add origin https://github.com/TUO-USERNAME/montecarlo-coffee-ecommerce-demo.git
git push -u origin main
```
3. Vai su [Vercel](https://vercel.com/new), importa la repository e clicca **Deploy**.
